# Roguelike

Консольное игровое roguelike-приложение на языке программирования JavaScript, c использованием библиотеки blessed, в духе классической игры Rogue 1980 года разработки. 

## Используемые инструменты и технологии:
- ES14
- TypeScript
- Node.js
- blessed

## Архитектура и парадигма программирования
Используется многослойная архитектура:
1. Слой представления (Presentation);
2. Слой бизнес-логики (Domain);
3. Слой доступа к данным (Data Layer);

Используется парадигма программирования - ООП.
